Kernel: Suvkernel 6.18 (6.18.33, Android Common Kernel android17-6.18)

This is the first build on the 6.18 kernel. Flash it once from recovery;
later 6.18 builds come over the air.

Root
- KernelSU Next patches the boot image with its own android17-6.18
  module (Install > select the boot image > KMI android17-6.18)

Camera
- Video recording works; the encoder no longer stalls on the first frame

Mobile data and network
- Mobile data and IMS work on 6.18
- The modem name server starts once instead of restarting every 5 seconds
- Apps can no longer read the Wi-Fi MAC address or the neighbour table
  over netlink

Under the hood
- The vendor drivers drop the code paths for older kernels
